# CSS Learning & Styling Journey 🎨

Welcome to my **CSS** repository! Following my HTML practice, this repository serves as a structured digital log where I document my progress, experiments, and styling projects while mastering Cascading Style Sheets.

---

## 📂 Repository Structure & File Overview

Here is a breakdown of the core files included in this repository and the CSS concepts explored in each:

| File Name | Primary Topic / Concept | Description |
| :--- | :--- | :--- |
| `basic.html` | Introduction to CSS | Applying basic styling rules to HTML elements. |
| `boarders.html` | Box Model & Borders | Experimenting with border widths, styles, and shapes. |
| `bordercolor.html` | Border Styling | Customizing border colors for visual hierarchy. |
| `classselector.html` | Class Selectors | Targeting specific elements using `.class` selectors. |
| `colourscss.html` | Colors & Backgrounds | Applying text colors, backgrounds, and visual tones. |
| `creatingidforpara.html` | ID Selectors | Using unique `#id` selectors to style specific paragraphs. |
| `fontsize.html` | Typography (Size) | Managing text scaling and font dimensions. |
| `fontstyle.html` | Typography (Style) | Exploring font families, weights, and text styling. |
| `margins.html` | Spacing & Layout (Margins) | Controlling outer spacing and element positioning. |
| `padding.html` | Box Model (Padding) | Managing inner spacing between content and borders. |
| `simplereportcard.html` | Practice Layout | A simple structured page to test basic styling rules. |
| `reportcardwithcss.html` | Styled Project | An advanced practical layout combining tables, colors, and box models. |
| `universalselector.html` | Universal Selector | Applying global styles using the `*` selector. |

## 🛠️ What I Am Learning & Practicing

Through building these files, I am strengthening my understanding of:
* Targeting elements using tag, class, and ID selectors.
* Controlling page layout using margins, padding, and borders (The Box Model).
* Customizing typography with font sizing and styles.
* Enhancing visual aesthetics using colors and backgrounds.
