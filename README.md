# CSS Learning & Styling Journey 🎨

Welcome to my **CSS** repository! Following my HTML practice, this repository serves as a structured digital log where I document my progress, experiments, and layout projects while mastering Cascading Style Sheets—from basic selectors and the box model to modern responsive layouts using Flexbox and CSS Grid.

---

## 📂 Repository Structure & File Overview

Here is a complete breakdown of the files included in this repository and the CSS concepts explored in each:

| File Name | Primary Topic / Concept | Description |
| :--- | :--- | :--- |
| `basic.html` | Introduction to CSS | Applying basic styling rules to HTML elements. |
| `universalselector.html` | Universal Selector | Applying global styles across a page using the `*` selector. |
| `classselector.html` | Class Selectors | Targeting specific groups of elements using `.class` selectors. |
| `creatingidforpara.html` | ID Selectors | Using unique `#id` selectors to style individual paragraphs. |
| `colourscss.html` | Colors & Backgrounds | Applying text colors, backgrounds, and visual tones. |
| `fontsize.html` | Typography (Size) | Managing text scaling and font dimensions. |
| `fontstyle.html` | Typography (Style) | Exploring font families, weights, and text styling. |
| `boarders.html` | Box Model & Borders | Experimenting with border widths, styles, and shapes. |
| `bordercolor.html` | Border Styling | Customizing border colors for visual hierarchy. |
| `margins.html` | Spacing (Margins) | Controlling outer spacing and element positioning. |
| `padding.html` | Box Model (Padding) | Managing inner spacing between content and borders. |
| `flexbox.html` | CSS Flexbox | Building flexible one-dimensional layouts and aligning items. |
| `wrapflex.html` | Flex Wrap | Controlling how flex items wrap across multiple lines. |
| `CSSgrid.html` | CSS Grid Basics | Creating two-dimensional row and column layouts. |
| `gridproperties.html` | Grid Properties | Defining grid templates, tracks, gaps, and sizing. |
| `gridalign.html` | Grid Alignment | Aligning and justifying items within grid containers. |
| `simplereportcard.html` | Practice Layout | A simple structured page to test basic styling rules. |
| `reportcardwithcss.html` | Styled Project | A complete layout combining tables, colors, and box model styling. |

## 🛠️ What I Am Learning & Practicing

Through building these files, I am strengthening my understanding of:
* Targeting elements cleanly using universal, tag, class, and ID selectors.
* Controlling spacing and structure with the CSS Box Model (margins, borders, and padding).
* Customizing typography, font scales, and color schemes.
* Building modern, structured page layouts using **Flexbox** and **CSS Grid**.
